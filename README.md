# Борис Рыков — проекты по аналитике и автоматизации

Разрабатываю инструменты на Python и SQL для отчётности, учёта и обработки данных. В личных проектах применяю LLM для разбора текстов и проверяю результаты по структуре и источникам.

## Система учёта мебельного производства

Внедрил систему учёта заказов, клиентов, дилеров и материалов на PostgreSQL. В панели владельца видны заказы под риском, дефицит материалов и стадии производства. Система автоматически формирует PDF-договоры и отправляет их по электронной почте.  
[Код, архитектура и скриншоты](https://github.com/borrykov/mebel-project)

## Монитор котировочных сессий

Python-сервис для предварительного отбора закупок. Собирает карточки и документы, применяет формализованные условия отбора и использует LLM для извлечения требований из текста. Рассчитывает экономику сделки по доступным входным данным и помечает недостающие сведения. Telegram-бот запускает проверку и показывает статус, SQLite хранит очередь и историю разбора.

**Пример результата на вымышленных данных**  
Лот — поставка 20 единиц товара. В карточке указано количество. Допустимый аналог требует уточнения по ТЗ. Стоимость доставки неизвестна. Статус — требуется проверка, итоговую маржу пока рассчитать нельзя.

## Подбор телефонов по объявлениям Авито

Разработал процесс проверки объявлений для подбора телефонов в Москве. Описал, как сверять заявленные модель, память и состояние, учитывать признаки магазина или объявления-приманки и оформлять результат для клиента. В карточке результата отдельно фиксируются сведения продавца, замеченные риски и вопросы перед встречей.

**Пример результата на вымышленных данных**  
Телефон 256 ГБ, 72 000 ₽, Москва. По объявлению аккумулятор 91%. Профиль выглядит как профиль частного продавца. Наличие конкретного экземпляра и отсутствие ремонта требуют уточнения. Следующий шаг — запросить подтверждение характеристик и согласовать проверку при встрече.

## Дайджест новостей Германии

Telegram-бот на Python для тематической выборки новостей по энергетике и политике Германии. Бот собирает публикации за выбранный период, анализирует их через Codex CLI, проверяет формат ответа и формирует дайджест со ссылками на исходные посты. В проекте есть тесты обработки данных, настройки окна выборки и фоновый запуск через launchd на macOS.
